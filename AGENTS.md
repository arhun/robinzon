# AGENTS.md — Инструкции для AGI и моделей Anthropic

## Проект: robinzon

Этот файл является головным инструкционным документом для AI-агентов (AGI, Anthropic Claude, Antigravity CLI).

## Правила работы
1. Перед началом работы изучи структуру проекта и актуальные промпты в папке `prompts/`.
2. Соблюдай единый стиль кода, существующие паттерны и структуру директорий.
3. Не выводи и не коммить секреты, ключи API и содержимое `.env`.
4. Не выполняй деструктивные команды без явного подтверждения пользователя.

## Структура проекта
- `prompts/` — рабочие промпты (`promt.md`, `promt2.md`, `promt3.md`).
- `.antigravityignore` — исключения для индексации Antigravity.
- `.gitignore` — стандартные исключения Git.
